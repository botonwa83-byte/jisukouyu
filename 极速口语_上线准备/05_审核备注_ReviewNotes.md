# 审核备注 Review Notes（中英双语）

## 中文

本 App 是英语口语跟读练习工具，无需注册登录即可使用全部核心功能。

- 麦克风与语音识别仅用于跟读评分：录音只在本机处理，评分完成后立即删除，不上传。
- App 内「AI 点评」「对练」功能需要用户在设置中自行填写第三方 AI 服务商的接口地址与 API Key（如 DeepSeek）。若未配置，这两个入口会提示前往设置，不影响其他功能。审核时如需体验 AI 功能，可在设置 → AI 设置中填入任意有效的 DeepSeek API Key。
- 应用不含内购、不含广告、不含第三方追踪。

## English

This app is an English shadowing-practice tool. All core features work without any sign-up.

- Microphone and Speech Recognition are used only for on-device pronunciation scoring. Recordings are deleted right after scoring and never uploaded.
- The "AI Review" and "AI Chat" features require the user to configure their own third-party AI provider endpoint and API key (e.g. DeepSeek) in Settings. Without configuration, these entries simply prompt the user to set them up; the rest of the app is unaffected.
- No IAP, no ads, no third-party tracking.
