# App 隐私问卷答案

位置：ASC → App 隐私 → 编辑。与 `docs/privacy.html`、`PrivacyInfo.xcprivacy` 保持一致。

## 关键差异（相比纯离线 App）

本 App 会把「句子文本 + 你的跟读转写」发送到**用户自行配置的 AI 服务商**（如 DeepSeek / OpenAI 兼容端点），用于发音点评与情景对话。录音不离开设备，API Key 存本机钥匙串。

## 第一题：是否收集数据？

**选择：是（收集以下两类，均为开发者不直接接触的第三方处理）**

| 数据类型 | 收集？ | 用途 | 是否关联身份 | 是否追踪 |
|---|---|---|---|---|
| 用户内容（其他用户内容文本） | 是 | App 功能 | 否 | 否 |
| 标识符 | 否 | — | — | — |

## 逐类核对表

| 数据类别 | 是否收集 |
|---|---|
| 联系信息 / 健康与健身 / 财务信息 / 位置 / 敏感信息 / 通讯录 | 否 |
| 用户内容（音频数据） | 否（录音仅本机评分，即时删除） |
| 用户内容（其他用户内容） | 是：转写文本与句子文本，经用户配置的第三方 AI 处理 |
| 浏览/搜索记录 / 使用数据 / 标识符 / 诊断 | 否 |

## 支撑事实

- 无账号、无开发者服务器、无广告/统计/追踪 SDK。
- 麦克风与语音识别仅本机；录音评分后即删。
- API Key 存钥匙串（WhenUnlockedThisDeviceOnly），不回显、不入 iCloud 备份。
- PrivacyInfo.xcprivacy：不追踪、无收集数据类型、仅 UserDefaults（CA92.1）。
